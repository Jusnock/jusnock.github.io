## Resumen de Formación

* **Entidad:** Cisco Networking Academy
* **Período:** 2024 – 2025
* **Objetivo:** Adquisición de conocimientos sólidos en diseño, configuración, resolución de problemas y mantenimiento de redes IP medianas y corporativas.

---

## Competencias Desarrolladas

1. **Conmutación LAN (Switching):**
    * Configuración de puertos de acceso y troncales (*Trunk 802.1Q*).
    * Protocolo Spanning Tree (STP / RSTP) para prevención de bucles en capa 2.
    * Configuración de EtherChannel / agregación de enlaces.

2. **Enrutamiento IP (Routing):**
    * Enrutamiento estático y rutas por defecto.
    * Conceptos de enrutamiento dinámico (OSPF de área única, métricas de costo, cálculo Dijkstra).
    * Enrutamiento Inter-VLAN (*Router-on-a-Stick* y switches de capa 3).

3. **Servicios IP y Seguridad de Capa 2:**
    * Listas de Control de Acceso (ACLs estándar y extendidas).
    * Network Address Translation (NAT estático, dinámico y PAT/Sobrecarga).
    * Mitigación de ataques de capa 2 (*DHCP Snooping, Dynamic ARP Inspection - DAI, Port Security*).
